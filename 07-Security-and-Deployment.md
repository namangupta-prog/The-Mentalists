# 07. Security and Deployment

## 1. Security
Security helps protect user information and prevent unauthorized access.

Important considerations include:
- Authentication where required.
- Appropriate permissions for data operations.
- Validation of submitted information.
- Protection of private user data.
- Keeping secret keys and credentials out of public frontend code.

The specific security controls enabled in SKILLCHECK should be verified in the application configuration.

## 2. Authentication and Authorization
Authentication identifies a user. Authorization determines which resources that user is allowed to access.

These controls should be configured according to the needs of workers, employers, and administrators where applicable.

## 3. Deployment
SKILLCHECK is hosted on Base44 and can be accessed through a web browser.

**Live Website:** https://fast-skill-proof-pro.base44.app

## 4. GitHub Repository
GitHub is used to maintain the project's documentation and collaborate on repository files.

The GitHub repository and the live Base44 website serve different purposes: one stores project materials, while the other provides access to the running application.

## Conclusion
Security and deployment are important parts of delivering a reliable web application. The actual controls and hosting configuration should be documented according to the current setup.
