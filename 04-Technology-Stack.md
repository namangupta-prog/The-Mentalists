# 04. Technology Stack

## 1. Introduction

SKILLCHECK is a web-based platform designed to connect skilled individuals with employers looking for suitable workers. The project uses Base44 as its AI-powered application development platform.

This document describes the technologies used or intended for the project. Exact implementation details should be verified against the current application and its available source code.

## 2. Application Development Platform

### Base44

Base44 is the platform used to build and host the SKILLCHECK web application.

**Purpose:**
- Develop the website using AI-assisted tools.
- Build and modify application pages and features.
- Preview the application during development.
- Publish the application online.

**Live application:** https://fast-skill-proof-pro.base44.app

## 3. Frontend Technologies

The frontend is the part of the website users see and interact with.

Its responsibilities include:
- Displaying the home page and navigation bar.
- Providing entry points for workers and employers.
- Displaying user information and available features.
- Supporting navigation between application pages.
- Providing a clear and user-friendly interface.

**Note:** The exact frontend framework and styling libraries should be confirmed from the project's source code before naming specific technologies such as React, Vite, or Tailwind CSS.

## 4. Backend Technologies

The backend handles application operations that take place behind the user interface.

Depending on the implemented features, backend responsibilities may include:
- Processing user requests.
- Managing user authentication.
- Retrieving and updating application data.
- Supporting worker and employer workflows.
- Applying access controls to protected information.

Base44 provides application development and backend capabilities. The specific services enabled in SKILLCHECK should be documented after verification.
